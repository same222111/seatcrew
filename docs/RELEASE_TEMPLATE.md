## SeatCrew release

**Downloads** (attached below): Windows installer `SeatCrew-<version>-windows-setup.exe` or portable `.zip`, macOS `SeatCrew-<version>-macos.dmg` (not notarized: right-click → Open the first time), Linux `SeatCrew-<version>-x86_64.AppImage`.

What changed in this version: see [CHANGELOG.md](https://github.com/same222111/seatcrew/blob/main/CHANGELOG.md). The automatic list of merged pull requests follows below.

**Honest notes**
- Paid providers (video, image, 3D, cloud TTS and paid LLMs) are tested with mocked HTTP only. The no-key path (edge-tts plus DRAFT visuals) and local Ollama are tested for real.
- Videos made without real voice and real visuals are labeled DRAFT previews for checking timing. They are not a sample of finished output, and no draft video is attached to a release as a product demo.
- Trading is paper only. This is educational software, not financial advice.
- Clone a voice only with the speaker's explicit permission.
